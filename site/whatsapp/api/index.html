API reference

Every operation of Meta's v23.0 specification is routed and validated. Real behavior means the mock simulates it with state; the others answer with Meta's own example, valid against the response schema.

Conventions

  • Base URL: http://localhost:3010/v23.0, the same path Meta uses.
  • Authentication: Authorization: Bearer <any token>. A call without one is refused, as Meta does.
  • Errors: Meta's envelope, {"error":{"message","type":"OAuthException","code","error_data","fbtrace_id"}}, with Meta's codes.
  • Webhooks: Meta's entry[].changes[] body, signed with x-hub-signature-256 when WEBHOOK_SECRET is set.
  • Versions: each Graph version is its own vendored spec; a new one is a new spec/<version> folder.

The panel's API tab carries the same operations with a ready curl for each.
