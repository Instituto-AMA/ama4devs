WhatsApp, Asaas e SMS rodando na sua máquina.

Simuladores das APIs de que seu produto depende, para desenvolvimento local, testes e CI, mais um gerador de dados brasileiros válidos. Aponte sua aplicação para o localhost: mesmos caminhos, mesmos corpos, mesmos webhooks. E o tempo anda quando você manda: um mês de cobrança roda em um segundo, e você vê o seu código reagir.

Rode na sua máquina.

Quatro jeitos, do mais rápido ao mais completo. As imagens são públicas: nenhum login.

Imagem pronta

O jeito mais rápido: a imagem direto do GHCR.

Mock do WhatsApp

docker pull ghcr.io/instituto-ama/whatsapp-mock:latest
docker run -d -p 3010:3010 ghcr.io/instituto-ama/whatsapp-mock:latest

Painel e API em localhost:3010

Mock do Asaas

docker pull ghcr.io/instituto-ama/asaas-mock:latest
docker run -d -p 45445:45445 -e CLOCK_MODE=VIRTUAL_FLOWING \
  ghcr.io/instituto-ama/asaas-mock:latest

Painel e API em localhost:45445, com o relógio virtual ligado. O Asaas acha o WhatsApp, o SMS, o Mailpit e o gerador sozinho: cada cobrança já avisa o pagador por e-mail, WhatsApp e SMS, cada canal quando o cliente tem o contato correspondente.

Mock de SMS

docker pull ghcr.io/instituto-ama/sms-mock:latest
docker run -d -p 8899:8899 ghcr.io/instituto-ama/sms-mock:latest

Painel e API em localhost:8899: a caixa do celular do pagador.

Gerador

docker pull ghcr.io/instituto-ama/generator-mock:latest

UI e API em localhost:45450

Mailpit, a caixa dos e-mails ao pagador

docker run -d -p 8025:8025 axllent/mailpit:v1.31.4

Caixa de entrada em localhost:8025

No seu docker-compose

Para subir junto com a sua aplicação, no compose dela. Nada para ligar: o Asaas acha o WhatsApp, o SMS, o Mailpit e o gerador pelo nome do serviço.

services:
  asaas:
    image: ghcr.io/instituto-ama/asaas-mock:0.13.0
    ports:
      - '45445:45445'
    environment:
      ASAAS_API_KEY: '$$aact_hmlg_local'   # `$$` é um `$` literal no compose
      CLOCK_MODE: VIRTUAL_FLOWING
    depends_on: [whatsapp, mailpit, sms, generator]
    volumes:
      - asaas-data:/data

  whatsapp:
    image: ghcr.io/instituto-ama/whatsapp-mock:0.5.0
    ports:
      - '3010:3010'
    environment:
      WEBHOOK_URL: http://minha-app:4000/webhooks/whatsapp   # a sua aplicação
      MOCK_ALLOWED_HOSTS: whatsapp   # a sua aplicação chama por este nome
    volumes:
      - whatsapp-data:/app/data

  mailpit:
    image: axllent/mailpit:v1.31.4
    ports:
      - '8025:8025'

  sms:
    image: ghcr.io/instituto-ama/sms-mock:0.2.0
    ports:
      - '8899:8899'

  generator:
    image: ghcr.io/instituto-ama/generator-mock:0.5.0
    ports:
      - '45450:45450'
    environment:
      ASAAS_API_KEY: '$$aact_hmlg_local'   # a mesma chave, para preencher o mock do Asaas

volumes:
  asaas-data:
  whatsapp-data:

Da sua aplicação: http://asaas:45445/v3 e http://whatsapp:3010/v23.0. Os dados fake em http://generator:45450/v1. Os avisos ao pagador em localhost:8025 (e-mail), localhost:3010 (WhatsApp) e localhost:8899 (SMS).

Gerar do código

Para rodar a partir do código-fonte, ou depois de alterar um mock.

git clone https://github.com/Instituto-AMA/ama4devs.git
cd ama4devs

Mock do WhatsApp

docker build -t whatsapp-mock mocks/whatsapp
docker run -d -p 3010:3010 whatsapp-mock

Mock do Asaas

docker build -t asaas-mock mocks/asaas
docker run -d -p 45445:45445 -e CLOCK_MODE=VIRTUAL_FLOWING asaas-mock

Mock de SMS

docker build -t sms-mock mocks/sms
docker run -d -p 8899:8899 sms-mock

Gerador

docker build -t generator-mock mocks/generator
docker run -d -p 45450:45450 generator-mock

Com o WhatsApp, o SMS e o Mailpit no ar, o Asaas acha os três sozinho, como na imagem pronta, e o gerador acha o Asaas.

Subir tudo junto

Os quatro mocks e o Mailpit, já conectados. Toda cobrança do Asaas avisa o pagador por e-mail (no Mailpit), por um template de WhatsApp (no mock do WhatsApp) e por SMS (no mock de SMS), cada canal quando o cliente tem o contato correspondente. O gerador preenche a conta com dados de teste quando você pede.

Uma coleção de mocks.

Cada mock é uma imagem Docker para linux/amd64 e linux/arm64. Sobe já configurado, guarda o estado num volume e traz um painel que mostra o que a API real nunca deixa ver. Três APIs de provedores e um gerador de dados estão prontos hoje; mais provedores de pagamento e bancos estão a caminho.

Mock do WhatsApp

A Cloud API da Meta Graph API v23.0, roteada e validada contra o próprio arquivo OpenAPI da Meta, e um painel no estilo WhatsApp Web onde você é o usuário do outro lado.

  • Mensagens de todos os tipos, templates com revisão, mídia, áudios de voz, confirmações de leitura.
  • Ligações com áudio WebRTC real e a permissão do usuário para ligar.
  • Empresa, WABAs e números, com o onboarding pelo código por SMS.
  • Webhooks assinados com x-hub-signature-256.

Mock do Asaas

A API v3 do Asaas, o gateway de pagamento, com as regras de negócio capturadas do sandbox real e um relógio virtual que você move na mão.

  • Clientes, Pix, boleto, cartão de crédito, parcelamento, assinatura, split.
  • Webhooks entregues no localhost, com as regras reais de retentativa.
  • Um relógio que você avança: cobranças vencem, o cartão cai em D+32.
  • Cartão salvo cobrado no vencimento, com as retentativas do Asaas.
  • Notificações ao pagador por e-mail, WhatsApp e SMS.

Mock de SMS

Um gateway de SMS que responde como o de verdade: a API nativa, a compatível com a Twilio e uma simples GET/POST, com o ciclo de vida da mensagem rodando e os webhooks saindo.

  • Três formatos de API: o nativo, o compatível com a Twilio e um simples, com long poll para os testes.
  • O ciclo de vida roda: na fila, enviada, entregue — e números mágicos que falham de propósito.
  • Segmentos GSM-7 e UCS-2 contados, e o código de OTP extraído para você.
  • Webhooks de status e de entrada assinados com x-sms-signature.

Gerador

Dados brasileiros válidos, os mesmos para a mesma seed: pessoas, empresas, CPF, CNPJ, CNH, PIS, RG, endereços com faixas de CEP reais, cartões, contas bancárias e chaves Pix. Ele preenche o mock do Asaas e responde à consulta de crédito do Direct Data nos caminhos do próprio provedor.

  • Todo documento brasileiro, válido e mascarado: CPF, CNPJ, CNH, PIS, RG, CEP, cartões, contas, chaves Pix.
  • Uma chamada popula o mock do Asaas com clientes e cobranças.
  • A consulta de crédito do Direct Data, nos caminhos do próprio provedor.
  • A mesma UI roda no navegador, sem container.
