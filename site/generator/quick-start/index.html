Quick start

From docker run to reproducible test fixtures and instant Asaas mock population. Every command below runs as written against a fresh container.

  1. Run it

    Run the generator container in Docker. In this repository, running make up brings it automatically alongside the Asaas mock.

    docker run --rm -p 45450:45450 ghcr.io/instituto-ama/generator-mock:latest

    The service listens on port 45450. You can verify its health status:

    curl http://localhost:45450/health

  4. Validate documents

    Validate CPF, CNPJ, CNH, or PIS strings directly against official checksum algorithms:

    curl http://localhost:45450/v1/validate/cpf/11144477735
    {
  "type": "cpf",
  "value": "11144477735",
  "valid": true
}

  5. Populate Asaas

  6. Interactive UI

    Open http://localhost:45450 to view the local web UI, or explore the hosted web app on GitHub Pages. The UI lets you generate, inspect, format, copy, and export data in JSON, CSV, or tabular formats.
