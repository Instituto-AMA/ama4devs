WhatsApp e Asaas rodando na sua máquina.

Simuladores das APIs de que seu produto depende, para desenvolvimento local, testes e CI, começando pelo WhatsApp e pelo Asaas. Aponte sua aplicação para o localhost: mesmos caminhos, mesmos corpos, mesmos webhooks. E o tempo anda quando você manda: um mês de cobrança roda em um segundo, e você vê o seu código reagir.

git clone https://github.com/Instituto-AMA/ama4devs.git
cd ama4devs && make setup   # WhatsApp, Asaas, Mailpit

Uma coleção de mocks de provedores.

Cada mock é uma imagem Docker para linux/amd64 e linux/arm64. Sobe já configurado, guarda o estado num volume e traz um painel que mostra o que a API real nunca deixa ver. Dois estão prontos hoje; mais provedores de pagamento e bancos estão a caminho.

Mock do WhatsApp

A Cloud API da Meta Graph API v23.0, roteada e validada contra o próprio arquivo OpenAPI da Meta, e um painel no estilo WhatsApp Web onde você é o usuário do outro lado.

  • Mensagens de todos os tipos, templates com revisão, mídia, áudios de voz, confirmações de leitura.
  • Ligações com áudio WebRTC real e a permissão do usuário para ligar.
  • Empresa, WABAs e números, com o onboarding pelo código por SMS.
  • Webhooks assinados com x-hub-signature-256.
docker run --rm -p 3010:3010 \
  ghcr.io/instituto-ama/whatsapp-mock:latest

Mock do Asaas

A API v3 do Asaas, o gateway de pagamento, com as regras de negócio capturadas do sandbox real e um relógio virtual que você move na mão.

  • Clientes, Pix, boleto, cartão de crédito, parcelamento, assinatura, split.
  • Webhooks entregues no localhost, com as regras reais de retentativa.
  • Um relógio que você avança: cobranças vencem, o cartão cai em D+32.
  • Notificações ao pagador por e-mail e WhatsApp.
docker run --rm -p 45445:45445 \
  -e CLOCK_MODE=VIRTUAL_FLOWING \
  ghcr.io/instituto-ama/asaas-mock:latest

Suba os dois juntos.

O compose do repositório sobe os dois mocks e o Mailpit, já ligados entre si. Toda cobrança que o mock do Asaas cria avisa o pagador duas vezes: um e-mail que chega no Mailpit e um template de WhatsApp enviado pela Cloud API do mock do WhatsApp. Nenhum passo na mão.

  1. Suba tudo

    git clone https://github.com/Instituto-AMA/ama4devs.git
cd ama4devs
make setup        # sobe os mocks e grava os endereços no .env

  2. Abra as três telas

    ServiçoEndereçoO que você abre ali
    Mock do WhatsApphttp://localhost:3010O painel de conversas, templates, números, ligações; a API em /v23.0
    Mock do Asaashttp://localhost:45445O painel do simulador e o relógio; a API em /v3
    Mailpithttp://localhost:8025Os e-mails enviados aos pagadores

  3. Aponte sua aplicação para eles

    Grave os endereços no ambiente do seu projeto e troque as URLs base:

    make setup TARGET_ENV=../meu-app/.env
    - https://graph.facebook.com/v23.0
+ http://localhost:3010/v23.0
- https://api-sandbox.asaas.com/v3
+ http://localhost:45445/v3
