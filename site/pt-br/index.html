WhatsApp e Asaas rodando na sua máquina.

Dois servidores de mock para desenvolvimento local, testes automatizados e CI. Aponte a sua aplicação para o localhost no lugar da API real: mesmos caminhos, mesmos corpos, mesmos webhooks. Sem conta, sem credencial, sem fatura.

Dois mocks, um para cada API

Cada um é uma única imagem Docker para linux/amd64 e linux/arm64, já sobe configurado e mantém o estado em um volume.

Mock do WhatsApp

A WhatsApp Cloud API da Meta Graph API v23.0, simulada a partir da especificação OpenAPI da própria Meta, mais um painel no estilo WhatsApp Web em que você é o usuário do outro lado.

  • Mensagens de todos os tipos, templates com revisão, mídia, reações, recibos.
  • Ligações de voz com áudio WebRTC de verdade, permissões de chamada, áudios de voz.
  • Empresas, WABAs e números de telefone com ativação por código SMS.
  • Webhooks assinados com x-hub-signature-256.
docker run --rm -p 3010:3010 ghcr.io/instituto-ama/whatsapp-mock:latest
Ler a documentação do mock do WhatsApp

Mock do Asaas

A API v3 do Asaas, o gateway de pagamentos brasileiro, com regras de negócio capturadas do sandbox real e um relógio virtual que você adianta na mão.

  • Clientes, cobranças com Pix, boleto e cartão de crédito, parcelamentos, assinaturas.
  • Webhooks entregues no localhost, com as regras de retentativa reais.
  • Página de fatura do pagador com QR code Pix de verdade.
  • Notificações ao pagador por e-mail e WhatsApp.
docker run --rm -p 45445:45445 ghcr.io/instituto-ama/asaas-mock:latest
Ler a documentação do mock do Asaas

Os dois juntos

O arquivo compose do repositório roda os dois mocks e o Mailpit. Toda cobrança criada pelo mock do Asaas avisa o pagador duas vezes: um e-mail que chega no Mailpit e um template de WhatsApp enviado pela Cloud API do mock do WhatsApp. Tudo já sobe configurado, sem nenhuma etapa manual.

git clone https://github.com/Instituto-AMA/ama4devs.git
cd ama4devs
make setup        # sobe os mocks e escreve os endereços deles no .env
ServiçoEndereçoO que você abre lá
Mock do WhatsApphttp://localhost:3010O painel de conversa, templates, números, ligações; a API em /v23.0
Mock do Asaashttp://localhost:45445O painel do simulador; a API em /v3

Para apontar outra aplicação para eles: make setup TARGET_ENV=../my-app/.env.
