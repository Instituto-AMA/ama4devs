Início rápido

Do docker run a chamadas com determinismo e população automática do mock do Asaas. Cada comando abaixo pode ser executado como está escrito.

  1. Suba

    Execute o container oficial do gerador. A porta padrão é 45450 e o serviço fica pronto em milissegundos sem dependências de banco de dados.

    docker run --rm -p 45450:45450 ghcr.io/instituto-ama/generator-mock:latest

    Verifique o status do serviço chamando o endpoint de saúde:

    curl http://localhost:45450/health
    {
  "status": "ok",
  "service": "generator",
  "version": "0.1.0"
}

  4. Validação

    Valide se um CPF, CNPJ, CNH ou PIS atende aos cálculos matemáticos oficiais de dígitos verificadores e rejeição de sequências repetidas.

    curl http://localhost:45450/v1/validate/cpf/11144477735
    {
  "type": "cpf",
  "value": "11144477735",
  "valid": true
}

  5. Popule o Asaas

    Com o mock do Asaas em execução na porta 45445, popule clientes, empresas e cobranças (com proporção de pagamentos confirmados no sandbox) com um único comando:

    curl -X POST http://localhost:45450/_mock/asaas/populate \
  -H 'Content-Type: application/json' \
  -d '{"people":5,"companies":2,"chargesPerCustomer":2,"confirm":0.5}'

    Para semear automaticamente na inicialização do compose no repositório, defina no seu .env:

    GENERATOR_ASAAS_SEED_ON_BOOT=people=10,companies=3,charges=2,confirm=0.5

    Ao rodar make up no repositório ama4devs, o gerador sobe junto com o Asaas e popula a base no primeiro boot.

  6. Interface web

    O gerador conta com uma interface visual interativa completa. Quando executado em container local, acesse http://localhost:45450. No GitHub Pages, acesse ama4devs/generator/app/ para gerar diretamente no navegador sem necessidade de instalar nada.

    Consulte o status da integração com o Asaas pela API:

    curl http://localhost:45450/_mock/asaas/status
    {
  "asaasUrl": "http://localhost:45445",
  "panelUrl": "http://localhost:45445",
  "reachable": true,
  "customers": 7
}
