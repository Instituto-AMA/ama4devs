Pessoas, empresas, CPFs, CNPJs, endereços reais, cartões de teste, contas bancárias e chaves Pix gerados sob demanda — determinísticos com semente fixa ou aleatórios. Suba o container no localhost, chame pela API HTTP ou abra a interface interativa direto no navegador, sem backend.

Casos de uso.

Soluções diretas para testes de software que lidam com requisitos e ecossistemas fiscais e bancários brasileiros.

Preencher formulários em testes manuais

Chega de digitar 111.444.777-35 ou inventar nomes repetidos ao validar telas de cadastro. Abra o gerador no navegador ou faça um curl para obter uma pessoa completa com endereço correspondente, telefone com DDD da cidade e documentos formatados prontos para copiar e colar.

curl -s 'http://localhost:45450/v1/person?formatted=true'

Semear suítes de teste com determinismo

Em testes de integração e CI, dados randômicos criam testes instáveis. Ao fornecer uma semente fixa (como seed=e2e-run-42), o gerador reproduz exatamente os mesmos CPFs, nomes, empresas e valores em todas as execuções, garantindo asserções previsíveis e reprodutíveis.

curl -s 'http://localhost:45450/v1/company?count=3&seed=e2e-run-42'

Popular o mock do Asaas numa única chamada

Ao subir um ambiente de desenvolvimento limpo com o mock do Asaas (make up), a integração é automática: o gerador é descoberto sozinho e aparece no painel do Asaas em Integrações › Gerador com o botão Popular esta conta para a conta selecionada na topbar. Pela API, o gerador cria clientes, emite cobranças e simula pagamentos com um único POST.

curl -X POST http://localhost:45450/_mock/asaas/populate \
  -H 'Content-Type: application/json' \
  -d '{"people": 5, "companies": 2, "chargesPerCustomer": 2, "confirm": 0.5}'

Validar CPF e CNPJ antes de processar

Use o endpoint de validação rápido para verificar documentos em testes unitários e de API sem precisar carregar bibliotecas externas adicionais no seu backend de desenvolvimento.

curl http://localhost:45450/v1/validate/cpf/11144477735
# → {"type":"cpf","value":"11144477735","valid":true}

A API numa tabela.

Rotas leves com respostas em JSON puro, CORS irrestrito para consumo direto do frontend e proteção local de acesso.

Método e rota Descrição Resposta de sucesso
GET /health Verificação de saúde do serviço {"status": "ok", "service": "generator", "version": "..."}
GET / Interface interativa da aplicação Arquivo HTML da interface
GET /core/:name.js Módulos ES browser-native do gerador Código JavaScript nativo (sem transpilação)
GET /v1/kinds Lista dos 12 tipos de dados suportados {"kinds": [{"id": "person", "label": "Pessoa"}, ...]}
GET /v1/validate/:type/:value Validador de documentos (cpf, cnpj, cnh, pis) {"type": "cpf", "value": "...", "valid": true|false}
GET /v1/:kind Gera itens com parâmetros (count, seed, formatted, state, gender, etc.) {"kind": "...", "seed": "...", "count": 1, "items": [...]}
GET /_mock/asaas/status Verifica conectividade e clientes no mock do Asaas {"asaasUrl": "...", "panelUrl": "...", "reachable": true, "customers": 12}
POST /_mock/asaas/populate Cria clientes e emite cobranças no mock do Asaas {"seed": "...", "customers": [...], "payments": [...], "errors": []}
