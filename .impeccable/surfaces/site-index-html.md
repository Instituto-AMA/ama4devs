## Scope

The ama4devs Pages site: home, and per mock (WhatsApp, Asaas) Overview with use cases, Quick start, API, Docs; English at the root, pt-BR under /pt-br/. Home and overviews are Persuade; Quick start, API and Docs are Read.

Audience: developers integrating WhatsApp Cloud API or Asaas, mostly Brazilian. Primary action: run both together (git clone + make setup). Proof: replays of real runs of the mocks, screenshots, the parity and contract suites.

## Direction contract

THESIS: The site is the mocks' own event log printed on a thermal receipt: every call, status and webhook a timestamped line, and the virtual clock feeds paper. Refuses the dark dev-tool hero with a terminal and a feature-card grid.

OWN-WORLD: one deep printer-body ground per page (violet home, bottle green WhatsApp, ultramarine Asaas); cool thermal paper with serrated torn edges; dot-matrix display type (Doto), Archivo prose, Martian Mono lines; controls are card-machine keypad keys: green confirm, yellow correct, red cancel.

STORY: the visitor sees their integration's lifecycle print in seconds, believes the mock behaves like the real API, and runs make setup.

FIRST VIEWPORT: headline, lead and the make setup command left on the ground; right, a printer slot feeding a receipt whose header is the base-URL swap, lines printing a replayed run, clock keys +1 / +7 / +32 days below.
